# Baseline profile — AOT-compiles startup hot paths so the first frame doesn't pay JIT/interpreter
# cost on cold start (a big win on low-end devices). Packaged into the release APK and applied by
# ProfileInstaller on API 29+ (so it benefits the Infinix-class devices too).

# MAXIMUM benefit a profile generated from a Macrobenchmark run is better (see notes); these rules
# give most of the gain without that setup and are safe (profiles only affect compilation).
#
